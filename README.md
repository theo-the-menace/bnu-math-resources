# BNU Mathematics & Applied Mathematics Resources

This repository collects study resources for the Mathematics and Applied Mathematics program at Beijing Normal University (BNU), Zhuhai campus.

## Contents

- `教材/` — Core textbooks and course reading materials. Textbook filenames have been normalized for clarity and consistency.
- `大数赛/` — Chinese National Undergraduate Mathematics Competition papers, answers, and related materials.
- `大英赛/` — National English Competition for College Students materials, including papers, answer keys, listening audio, and writing templates.
- `蓝桥杯/` — Blue Bridge Cup competition workspace, ready for future problem solutions and notes.

The repository is intended as a personal learning archive. Please respect the copyright and usage terms of the original materials.

## Repository language

The primary documentation language is English. A Chinese version is available in [README.zh-CN.md](README.zh-CN.md).
